# Rejected

Files that cannot be filed go here with a `REASON.md` note. Never delete them.

Reasons:

- Personal or sensitive information
- Confidential commercial material
- Unreadable or corrupt file
- Out of scope (not Victorian public policy)
- Duplicate of an existing source (link the existing source)
- Malware or unsafe file

Example `REASON.md`:

```markdown
# Rejection reason

- Original file: `example.pdf`
- Date: 2026-11-20
- Reason: Contains unredacted personal health information.
- Action: Removed from the repository; pointer retained for the record.
```
