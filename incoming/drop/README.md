# Drop Zone

Drop loose files here. Do not rename them, do not create subfolders, and do not worry about where they belong.

Run:

```bash
python incoming/triage.py
```

Then review and apply:

```bash
python incoming/triage.py --apply
```

Read [`../README.md`](../README.md) and [`../TRIAGE.md`](../TRIAGE.md) first.

**Do not drop personal, confidential or sensitive information here.** Redact it first, or use a restricted system outside this repository.
