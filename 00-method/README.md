# Method

This folder contains the thinking and delivery methods that sit behind every policy area. It is deliberately separate from the portfolios: a method should be reused, challenged and improved, not buried inside one policy document.

| File | Purpose |
|---|---|
| [`operator-method.md`](operator-method.md) | The non-linear, six-lens operating method: how to reframe, cut, add, sequence and red-team a policy area. |
| [`10x-efficiency-engine.md`](10x-efficiency-engine.md) | The v3.0 forensic efficiency engine: provenance tags, restriction density, fiscal verification, six-agent red team, human-AI co-design, Go/No-Go decision cards and 90-day pilots. |
| [`in-house-delivery-builder.md`](in-house-delivery-builder.md) | The v1 costed in-house delivery method: baseline, capacity, bulk procurement, bureaucracy offset, workforce transition. |
| [`in-house-delivery-builder-v2.md`](in-house-delivery-builder-v2.md) | The v2 method: mandatory primary research, self-healing verification, sensitivity testing and audit-proof sourcing. Supersedes v1. |
| [`policy-readme-template.md`](policy-readme-template.md) | The standard structure for every portfolio README. |
| [`evidence-standard.md`](evidence-standard.md) | Source hierarchy, confidence labels, numeric discipline and verification rules. |

## Which method to use

- **Starting a portfolio or reframe:** `operator-method.md`.
- **Auditing an existing department, agency or council function:** `10x-efficiency-engine.md`.
- **Designing a costed in-house delivery proposal:** `in-house-delivery-builder-v2.md`.
- **Writing a portfolio README:** `policy-readme-template.md`.
- **Checking a number or claim:** `evidence-standard.md`.

## The one rule

**No policy is an island.** Every portfolio README must name its cross-portfolio joins, its delivery partners and its evidence gaps. If it cannot, it is not ready.

## The one question

> If we were designing Victoria from scratch today, would we build it this way?

If the answer is no, the README must say what we would build instead, what it would cost to get there, and what we would stop doing to pay for it.
