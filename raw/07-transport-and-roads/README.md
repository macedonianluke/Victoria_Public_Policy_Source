# Raw: Transport and Roads

Sources for the [Transport and Roads portfolio](../../01-portfolio/07-transport-and-roads/README.md).

- File sources here by **primary policy relevance**.
- Use the naming convention `YYYY-MM-DD__publisher__short-title.ext` (or `YYYY-MM` / `undated` if the date is unknown).
- Every source gets a `.meta.md` sidecar from [`../_template/SOURCE.md`](../_template/SOURCE.md).
- Add a line to [`../MANIFEST.csv`](../MANIFEST.csv).
- Link the source from the portfolio README if it changes a material claim.
