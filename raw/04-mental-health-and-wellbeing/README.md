- Use the naming convention `YYYY-MM-DD__publisher__short-title.ext` (or `YYYY-MM` / `undated` if the date is unknown).
- Every source gets a `.meta.md` sidecar from [`../_template/SOURCE.md`](../_template/SOURCE.md).
