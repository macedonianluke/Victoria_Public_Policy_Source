## How to add a source

1. File the source in `raw/<portfolio>/` with a sidecar.
2. Add a row here with a unique ID.
3. State what it supports, not just what it is.
4. Add the confidence label.
5. If it contradicts another source, add a contradiction log line in `04-evidence/README.md`.
6. If it changes a portfolio README, update the README at the same time.

## A note on raw reviews and proposals

Sources marked `[C]/[D]` are secondary reviews, proposals or modelled estimates. They are useful for direction and hypothesis generation, but every material number must be traced to the primary source before it is published as fact.
